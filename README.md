# NLP assignment
This repository contains my solution to the Natural Language Processing assignment. 
The assignments cover various aspects and techniques in NLP, including:
* Text Preprocessing: Tokenization, stemming, lemmatization, stop-word removal, etc.
* Language Models: N-grams, Word2Vec, GloVe, Transformers, etc.
* Sequence Models: RNNs, LSTMs, GRUs, etc.
